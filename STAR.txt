InternPath 项目经历（STAR 法则）

项目名称：InternPath - 面向个人求职决策的 JD 分析与简历改造工作台
项目角色：后端 / 应用逻辑 / React + FastAPI 全栈开发
技术栈：React、Vite、TypeScript、FastAPI、Python、SQLite、Pydantic v2、HTTPX、OpenAI 兼容 SDK、Bilibili 搜索接口、PBKDF2 密码哈希

S（Situation，背景）
个人求职时需要反复阅读 JD、判断是否值得投递、改写简历并补齐项目证据。手工处理效率低，不同岗位之间也难以沉淀和比较。

T（Task，任务）
构建一个本地优先的个人求职工作台，支持账号登录、个人材料管理、JD 分析、投递决策、简历改造建议、历史记录和可选专家校验。

A（Action，行动）
1. 使用 React + Vite + TypeScript 构建前端工作台，承载登录、材料上传、JD 输入、结果展示、历史记录和专家调试区。
2. 使用 FastAPI 封装后端 API，复用既有 `service.py`、`ai_analyzer.py`、`database.py` 业务能力。
3. 使用 Pydantic 定义 `JobAnalysis`、`PersonalDecision`、课程、测验和历史记录等领域模型，保证模型输出、API 返回和持久化结构一致。
4. 使用 SQLite 保存账号、个人材料、JD 历史、分析报告和增强校验结果。
5. 通过 OpenAI 兼容 SDK 调用大模型，把非结构化 JD 转换为投递建议、关键缺口、简历表达和行动计划。
6. 保留 ai-service 的 RAG、证据校验和幻觉风险能力，但将其放入专家调试信息，不干扰主路径。
7. 使用 PBKDF2-HMAC-SHA256 保存密码哈希，并在后端 API 中用 bearer token 维护本地会话。

R（Result，结果）
项目从脚本式 Demo 收敛为完整的个人求职决策台。用户可以输入 JD 和个人材料，得到“建议投 / 谨慎投 / 不建议投”的决策、可复制的简历改造表达、需要补证据的经历和下一步行动；分析结果会自动保存到本机，便于持续复盘。
